# Review build verification

- Generated nine HTML routes. Checked all 125 internal links, including cross-page fragments, unique IDs, one H1 per page and referenced local images/scripts.
- Exercised the handler with valid and invalid input, a cross-origin request, a honeypot, absent provider settings, failed storage, rate limiting, duplicate retries and partial notification failure. The automated tests use controlled transport responses.
- Applied the SQL schema to PGlite (embedded PostgreSQL). Checked UUID receipt, replay with the same payload, rejection of changed data with the same key, the per-network limit, persisted delivery flags and denial of anonymous table and function access.
- Vercel built the review branch. Its preview requires Vercel access. An independent GitHub Actions job tested the build in Chromium at widths 320, 360, 390, 768, 1024, 1280 and 1440 px. All nine routes rendered with the expected status and without horizontal overflow.
- Keyboard skip link, mobile menu opening and Escape focus return, FAQ expansion, work filters, retained form entries after a failed request, and confirmation after a simulated server acknowledgment passed. An automated accessibility scan on mobile and desktop returned zero violations for its selected WCAG A/AA rules.
- The mobile Lighthouse run scored 92 for performance, 100 for accessibility, 100 for best practices and 69 for SEO on the intentionally unindexed review build. These are lab results. Homepage screenshots were also inspected at 390 and 1440 px.
